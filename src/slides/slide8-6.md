#### Sidebar : Verbage (Outbound)

<ul>
    <li><strong>Format nom d'une méthode</strong> : [verbe][nom d'objet de domaine]Async</li>
</ul>

| Verbe       | Sens        | Description                                   |
| ----------- | ----------- | --------------------------------------------- |
| Create      | Sortant     | Destination à distance                        |
| Save/Write  | Sortant     | Destination proche                            |
| Update      | Sortant     | Obj existant, Soit remote (API), soit DBB     |
| Delete      | Sortant     | Suppression                                   |
