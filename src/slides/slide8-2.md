#### les quatre projets de base

<ul>
    <li class="fragment">
        <strong>Domain</strong> : Les objects du domaine et la definition de ports primaires (<em>driving</em>) et secondaires (<em>driven</em>).
        <ul>
            <li>Le « quoi ».</li>
        </ul><br/>
    </li>
    <li class="fragment"><strong>Infrastructure</strong> : Les adaptateurs et les dépendances de ces adaptateurs.
        <ul>
            <li>Le « comment ».</li>
        </ul><br/>
    </li>
    <li class="fragment"><strong>Functions</strong> : Les points d'entrée.</li>
    <li class="fragment"><strong>Application</strong> : Les commandes (<em>commands</em>) et les requêtes (<em>queries</em>).
        <ul>
            <li class="fragment">Les deux projets se combinent pour mettre en œuvre du patron de conception médiateur.</li>
        </ul>
    </li>
</ul>
