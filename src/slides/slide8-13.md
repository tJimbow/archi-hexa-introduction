#### Le projet Application

<ul>
    <li class="fragment"><strong>Commandes</strong> : Commands
        <ul>
            <li>Une action qui a une modification comme objectif principale.</li>
            <li>Retourne uniquement le statut du changement demandé.</li>
        </ul>
    </li>
    <li class="fragment"><strong>Requêtes</strong> : Queries
        <ul>
            <li>Une action qui a pour but principal de récupérer les données.</li>
            <li>Retour des données si présentes.</li>
        </ul>
    </li>
    <li class="fragment">Typiquement les objets les plus proches du business dans le code.</li>
    <li class="fragment">Cela nous donne la capacité de limiter les nombres des objets « port driving » à injecter.</li>
</ul>
