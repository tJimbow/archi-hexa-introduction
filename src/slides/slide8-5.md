#### Sidebar : Verbage (Inbound)

<ul>
    <li><strong>Format nom d'une méthode</strong> : [verbe][nom d'objet de domaine]Async</li>
</ul>

| Verbe       | Sens        | Description                              |
| ----------- | ----------- | ---------------------------------------- |
| Get         | Entrant     | Soit remote (API), soit BDD              |
| Fetch       | Entrant     | Source probablement à distance           |
| Load/Read   | Entrant     | Source probablement proche               |
| Search      | Entrant     | Lancement d'un recherche                 |
